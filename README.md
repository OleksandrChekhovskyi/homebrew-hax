# Homebrew tap for hax

Homebrew formulae for [hax](https://usehax.dev), a minimalist, terminal-native coding agent
written in C. Sources live at [OleksandrChekhovskyi/hax](https://github.com/OleksandrChekhovskyi/hax).

## Install

```sh
brew install oleksandrchekhovskyi/hax/hax
```

Or `brew tap oleksandrchekhovskyi/hax` and then `brew install hax`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "oleksandrchekhovskyi/hax"
brew "hax"
```

## Maintenance

`Formula/hax.rb` is bumped automatically by the hax release workflow when a new version is
tagged. `brew test-bot` validates pushes and pull requests; see [Homebrew's tap
documentation](https://docs.brew.sh/Taps) for the rest.

Installs build from source by design: hax compiles in seconds, so bottles would add
maintenance without much benefit. The bottle machinery generated by `brew tap-new` (the
PR-only bottle upload in CI and the `publish.yml` workflow) is intentionally kept but dormant;
it becomes relevant only if formula bumps ever move to a pull-request flow.
